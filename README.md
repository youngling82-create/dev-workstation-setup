# 개발 워크스테이션 구축 미션

## 프로젝트 개요
이 프로젝트는 터미널, Docker, Git을 활용하여 재현 가능한 개발 환경을 구축하는 미션입니다.

**목표:**
- 터미널 기본 조작 숙달
- Docker를 이용한 컨테이너 실행 및 관리
- GitHub를 통한 버전 관리 및 협업 환경 구성
